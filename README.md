# JS Mini Projects

Welcome to the **JS Mini Projects** repository! This is a collection of beginner-friendly, practical web applications built using pure **Vanilla JavaScript** and **HTML5**. 

This repository is designed to demonstrate foundational frontend skills, focusing heavily on **DOM manipulation**, **event handling**, and **basic mathematical logic** in JavaScript.

---

## Featured Projects

### 1. Color Switcher
A simple yet interactive tool that allows users to dynamically change the background color of the page with a single click.
* **Core Concepts Covered:** Event listeners (`addEventListener`), target loops, and CSS variable manipulation.

### 2. BMI Calculator
A handy health utility application that takes a user's height and weight, calculates their Body Mass Index (BMI) in real-time, and provides immediate health category feedback (Underweight, Normal, Overweight).
* **Core Concepts Covered:** Form handling, input validation, mathematical formula implementation, and conditional logic.

---

## Tech Stack

* **HTML5:** Semantic structure
* **JavaScript (ES6+):** Clean, framework-free client-side logic

---

## Getting Started

To run these projects locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd js-mini-projects
   ```

3. **Open the projects:**
   * Simply double-click the `index.html` file of the respective project folder to open it directly in your web browser.
   * *Alternatively*, use the **Live Server** extension in VS Code for a better development experience.
